04 / 관측과 보정

SLAM을 실행한 뒤가
더 어려웠다.

중복 벽, 유리 출입문의 깊이 결손, 긴 복도의 회전 오차. 형상이 보인다는 것과 지도에 쓸 수 있다는 것은 달랐다.

같은 장소를 다시 촬영하면 누적 오차를 줄일 기회를 얻는다. 반복되는 문은 잘못된 루프 폐쇄를 만들 수 있어, 양방향 점군 정합을 통과한 제약을 그래프 계산에 사용했다.

05 / 관측 과정을 보는 시스템

어디를 다시 찍어야 할지
현장에서 알 수 있도록.

추후 360도 카메라나 이동 로봇으로 지도를 만들 때도 관측과 보정 결과를 함께 볼 수 있어야 한다. Ubuntu에서 ROS 2 Humble로 입력, 필터, 재방문 검사, 누적 최적화와 점군 발행을 분리했다.

74배치 · 기하 검사 통과 루프 91개 · 누적 최적화 20회 · 처리 약 95.36초. 기록 재생 실험의 처리량으로, 센서 전체 주기의 실시간 성능 보장과는 구분한다.

06 / 공간을 사람이 읽는 방법

3D로 구조를 보고,
사진으로 장소를 알아본다.

휴대폰 LiDAR의 근거리 깊이는 넓은 공간과 미관측 면에서 빈틈을 남겼다. TSDF, Poisson과 Gaussian 표현을 비교한 뒤, 1인칭 안내에는 실제 촬영 사진을 연결했다.

07 / 공간 기반 경로

내가 걸은 길이 아니라,
걸을 수 있는 공간에서.

넓은 로비는 바닥 전체가 이동 후보가 된다. 벽 주변에 24cm 여유를 두고, 모서리 통과를 차단한 12cm 격자에서 A*로 경로를 계산했다. 두 계단과 엘리베이터 후보는 층 사이의 연결로 다뤘다.

08 / 방문자의 현재 위치

실외 위치는 보정하고,
실내 진입은 확인한다.

휴대폰 OS의 위치와 헤딩을 표시하고, 칼만 필터와 정확도·잔차 게이트로 위치 튐을 처리한다. 저장 GNSS와 동시각 SLAM 지도 위치를 대조하니, 실내의 큰 편향은 평활화만으로 줄어들지 않았다.

현재 구현은 실외 위치 안내 → 입구 한 번 확인 → 실내 경로와 사진 안내다. 추가 수집한 약 112초의 IMU·기압으로 층간 이동을 살폈으며, 보행 추정과 GNSS/IMU EKF는 다음 단계다.

09 / 결과와 다음 연결

건물 밖에서 시작해,
실내 목적지까지.

전역 OSM 배경, 교내 48개 3D 건물, 학생회관 실측 지도를 한 화면에 놓았다. Figma는 화면 구성의 참고로 사용했고, Vercel로 배포했다.

알고리즘과 AI 활용의 구분

SIFT/RootSIFT, RANSAC, ICP, PGO, BA와 칼만 필터는 고전적 특징·기하·수치 알고리즘이다. 학습 기반 실험은 LoFTR, YOLO 마스크 후보, 고정 Gaussian 중심의 표현 학습으로 나눴다. 생성형 AI는 연구자가 정한 방법과 입력 형식에 맞춰 코드 수정과 화면 편집을 보조했다. 전체 설정과 비교 결과는 저장소 기술 보고서에 연결했다.
