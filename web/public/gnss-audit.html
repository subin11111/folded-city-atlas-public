비교 방법

GPS blob의 측정 시각을 중복 제거하고 동시각 SLAM 위치를 선형 보간했습니다. 보간 구간이 5초를 넘거나 촬영 범위 밖이면 대조값을 만들지 않았습니다. 실내 GNSS에 맞춰 지도를 다시 회전하거나 이동하지 않았습니다.

WGS84 → ECEF → ENU → SLAM 지도 순서로 변환합니다. 지도 배치는 축척 1의 회전과 이동이며 화면 이동 동 2m, 남 2m를 포함합니다.

현재 비교 기준은 Windows 이관본의 DB 최적화 포즈, 세션 배치 및 사진 기준점 보간으로 복원한 웹 지도 위치입니다. 웹 사진 189개의 위치와 0.1mm 이내로 일치하지만 원래 선택 포즈 CSV와 동일하다고 주장하지 않습니다.
배경의 복도는 공개된 보행 지도이며 현장 측량 도면이 아닙니다. 글로벌 보기의 실외 도로는 © OpenStreetMap contributors 자료를 사용합니다.
