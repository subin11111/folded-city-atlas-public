# 배경지도에 떠 보이던 실내 지도: 표시 높이 기준의 수정

## 원인

OpenFreeMap 벡터 배경은 현재 설정에서 지형 고도가 없는 평면이다. 별도로 그린 교내 지형을 이 평면 위로 올리기 위해 적용한 표시 변환이, 교내 지형을 숨긴 실내 보기에도 남아 있었다.

| 항목 | 값 |
| --- | ---: |
| 교내 표시 datum | 23.1828125m |
| 표시 지형 최저값 | 9.6m |
| 기존 공통 lift | 23.1828125 − 9.6 + 0.15 = 13.7328125m |
| 원본 1층 높이 | −1.55m |
| 배경 평면 위에 놓인 기존 1층 | 12.1828125m |

따라서 이번 현상은 실측 층간 높이의 변경이나 OSM에서 제공한 학생회관의 잘못된 표고 때문이 아니라 표시 좌표계의 기준 불일치였다. 학생회관의 절대 표고를 독립 기준점으로 측량한 것은 아니다.

## 수정

실내에서는 `z_display = z_local − z_1F + 0.08`을 사용한다. 1층 바닥은 0.08m, 2층은 4.23m에 표시된다. 0.08m는 평면과의 겹침을 방지하는 표시 여유다. 2층만 선택해도 기준은 1층으로 고정한다.

모든 실내 모델, 장소와 경로에 동일한 평행 이동을 적용하며 원본 JSON과 SLAM 좌표는 수정하지 않는다. 층간 차이 4.15m와 계단 polyline의 3D 거리는 불변이다. GNSS의 XY 정합도 바뀌지 않는다. 교내 전체 보기의 지형 lift는 별도로 유지한다.

## 경로와 고도의 의미

실내 A*는 층별 격자와 명시적 메인 계단·서브계단·엘리베이터 연결을 사용한다. 계단 비용은 XYZ polyline의 구간 길이 합이다. 같은 XY에 있어도 서로 다른 층의 셀은 계단 등의 연결 없이 인접하지 않는다.

실내 상대 고도와 교외 절대 표고는 다른 문제다. 이번 수정으로 실내 층간 탐색을 평면 탐색으로 바꾸지 않는다. 교외 경사·입구 턱·절대 표고를 연속적으로 계산하려면 측량 기준 또는 신뢰 가능한 지형·보행면 관측이 더 필요하다.

## 확인

- `web/test_world_map.mjs`: 1층의 배경 정합, 4.15m 층간 차이, 각 portal의 3D 길이 보존.
- `web/test_navigation.py`: 층간 무연결 차단, A*와 Dijkstra 거리 일치, 경로 polyline의 실제 3D 길이와 비용 일치.
- PRIME HALL 32.8m 경로와 메인 계단 연결 유지.
