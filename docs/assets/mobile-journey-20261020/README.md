## 화면 확인 환경

- 390×844에서 그립을 실제로 아래로 드래그해 접고, 위로 드래그해 펼치는 동작 확인.
- 방향키/Home/End로 세 높이 조절 및 접힌 목록의 inert 상태 확인.
- 320×568에서도 문서 너비=320·높이=568, 사진 top=0·bottom=568, 안내 패널 bottom=568 확인.
- 1280×800 데스크톱에서 장소 선택→경로→사진 안내, 지도 너비 1280px 확인.
- 원본/보정·비율·3D 전환, 미니맵, 추천 이동 41.8→38.4m, 이전 지점 이동 확인.
- Node 15개와 Python 29개, 총 44개 회귀 검사 통과. 배포 사전 검사 통과.

Chromium 반응형 화면에서 확인했다. iPhone Safari의 터치와 주소창 동작은 별도의 실기기 확인 항목이다. 이번 개편은 UI 변경이며 사진, 지도와 연결 데이터는 유지했다.
