# 다중 세션 지도 설계와 처리 단계

다섯 촬영본을 하나의 지도에 연결하되, 관측 검사와 내부 자세 보정, 세션 배치를 별도 단계로 나눈다. [연구 보고서](../README.md)에 이론과 결과를, [실험 이력](../README_HISTORY.md)에 단계별 선택을 정리했다.

## 설계 목표

실외에서 출입문을 지나 로비와 계단, 다른 층의 목적지로 이어지는 지도다. 계단과 경사를 한 높이로 평탄화하지 않고, 같은 XY의 다른 층은 명시적인 연결로 구분한다. 지도를 제작할 때 걸은 동선과 방문자 보행 경로는 별도로 만든다.

## 처리 계층

| 단계 | 입력 | 처리 | 출력 |
| --- | --- | --- | --- |
| 관측 해석 | 원본 DB | RGB-D, 신뢰도, 보정값과 그래프 검사 | 프레임 및 연결 원장 |
| 국소 측정 | RGB와 깊이 | 특징 대응, RANSAC, ICP와 미사용 관측 검사 | 상대 변환 후보 |
| 세션 내부 | 오도메트리와 재방문 | 4DoF/SE(3) PGO, 서브맵과 BA 비교 | 세션별 후보 포즈 |
| 지도 통합 | 선택 포즈와 교차 세션 측정 | xyz+yaw 강체 배치 | 공통 좌표의 점군 |
| 표시 | 점군과 실제 사진 | 표면 재구성, 층 구조와 텍스처 | GLB와 사진 원장 |
| 이동 공간 | 바닥과 장애물 후보 | 층별 격자와 문 및 계단 연결 | A* 탐색 입력 |

## 입력과 기준

`Node.pose`는 저장 오도메트리이며 `Admin.opt_poses`는 앱 저장 최적화 포즈다. 처음부터 최적화되지 않은 데이터 하나로 취급하지 않는다. 원본, 앱 저장본과 후처리 후보를 같은 관측 집합에서 비교한다.

각 연결 성분의 기준 포즈를 고정한다. 무효 변환과 추적 단절은 분리하고, 가까운 프레임 ID만으로 연결하지 않는다. 센서 공분산과 추가 모델 잡음의 가정도 구분한다.

## 연결 측정

영상 유사도는 후보를 찾는 단계다. 신뢰 깊이와 기하 지지가 있는 경우에 상대 변환을 구한다. 유리 너머 RGB와 다른 표면의 깊이가 섞이거나 반복 구조의 대응이 좁은 영역에 몰리는 경우를 확인한다.

같은 출입구의 연속 프레임 여러 개는 독립 장소 여러 곳과 다르다. 학습과 감사 역할을 기록하고, 학습 잔차만으로 연결을 채택하지 않는다.

## 최적화와 평가

기본 모델은 전체 정보행렬로 whitening한 연결 잔차와 블록 강건 손실이다. 4DoF, SE(3), Huber, DCS, 구역 공유 switch와 구조 제약을 단계별로 비교했다. 국소 RGB-D BA는 카메라와 landmark를 함께 추정하며, 이후 그래프에 측정을 전달하는 실험과 구분한다.

평가는 다음을 나누어 수행한다.

1. 목적함수와 수치 종료 조건.
2. 같은 원본 유한 패치의 거리와 겹침.
3. 학습에 쓰지 않은 관측의 일관성.
4. 벽, 계단과 출입구의 실제 형상 비교.
5. 기준점 및 현장 통행 확인.

마지막 항목은 후속 평가다. 기존 관측을 반복 사용한 지표는 독립 측량 성능과 구분한다.

## 현재 선택과 산출물

선택본은 실외 J01, 로비 N05, 실외 연결 H03, 2층 J04, 서브계단 H03이다. 세션 내부를 유지한 강체 배치로 2,251포즈와 3,493,208점의 통합 지도를 만들었다. 약한 연결과 국소 변형은 [연결 감사](experiments/2026-10-17-selected-working-map.md)에 기록했다.

최종 표시 모델은 `student_union_final_mesh_v9`다. Z02 높이 보정, 공유 외곽과 Gaussian 후보는 비교 결과이며 최종본에 모두 적용한 것은 아니다.

## 다음 단계

독립 기준점으로 지도 배치와 높이를 측정하고, 약한 출입구 및 층간 연결을 추가 촬영한다. 통행 원장은 문, 계단과 승강장의 실제 접근 조건을 포함하도록 확장한다. 새 방문자 측위는 별도 재위치 추정 모듈에서 지도와 연결한다.
