# 공개 저장소와 변경 반영

[공개 연구 저장소](https://github.com/subin11111/folded-city-atlas-public) / [실제 서비스](https://folded-city-atlas.vercel.app/)

공개본은 현재 관리 파일만으로 새로 시작한 독립 저장소다. 기존 Git 이력과 삭제한 개인 인계 문서는 옮기지 않는다. 기존 관리 저장소는 비공개로 유지하고 Vercel도 기존 저장소의 main을 계속 사용한다.

## 이후 수정 방법

평소처럼 기존 관리 저장소에서 수정하고 main에 커밋·푸시한다. 기존 Vercel 배포와 공개 스냅샷 반영이 각각 실행된다. 공개본에 직접 수정하면 다음 반영에서 덮어쓸 수 있으므로 수정 기준은 관리 저장소로 통일한다. 양방향 자동 병합은 하지 않는다.

## 공개본에 반영하는 것

`.public-export.json`의 허용 폴더와 최상위 파일만 대상으로 한다. 코드, 설정, 실험 기록, 공개용 이미지와 웹 결과물을 반영한다. 새 최상위 폴더를 추가할 때는 공개 정책도 함께 수정해야 한다.

개인 인계 문서, 인증정보, `.git`, 비공개 작업 폴더, 원본 DB와 압축 파일, 개인 문서 및 키 파일은 제외한다. 텍스트에서 토큰·개인키·전화번호 등의 패턴이 발견되면 공개 반영을 중단한다. 이미지 안의 얼굴과 안내문 등은 파일명이나 비밀값 검사만으로 판별할 수 없으므로 추가할 때 직접 확인해야 한다.

공개 저장소의 과거 커밋은 공개용 스냅샷만으로 쌓인다. 비공개 저장소의 Git 폴더나 과거 브랜치를 복사하거나 mirror push하지 않는다. 공개본 쓰기 권한은 해당 저장소 한 곳의 deploy key로 제한한다.

## 확인 방법

관리 저장소의 Actions에서 `Publish public snapshot` 실행 결과를 본다. 실패한 경우 공개본은 직전 상태를 유지한다. 수정 후 다시 main에 푸시하거나 해당 작업을 수동 실행할 수 있다. 동기화 실패가 기존 Vercel 배포의 중단을 의미하지는 않는다.
